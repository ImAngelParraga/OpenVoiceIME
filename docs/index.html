Setup

Install, configure, dictate.

OpenVoiceIME is built for users who already have an API token or a compatible self-hosted transcription server.

  1. 01
    Install the release APK

    Download the latest APK from this site and allow installation from your browser or file manager.

  2. 02
    Configure transcription

    Select OpenAI, Groq, or a custom OpenAI-compatible endpoint. Enter the model, token, language, and optional prompt context.

  3. 03
    Choose how to open dictation

    Grant microphone permission and enable OpenVoiceIME in Android keyboard settings. Keep your normal typing keyboard. Use Android's keyboard picker where it lists voice keyboards, or HeliBoard's microphone shortcut.

Keyboard setup

Keep typing. Switch to dictate.

Open Keyboard setup in OpenVoiceIME and choose Use HeliBoard or Keep my current keyboard. The guide includes download/settings buttons and a test field.

OpenVoiceIME is a voice-only keyboard. Gboard's microphone uses Google's voice typing and cannot be configured to open OpenVoiceIME. Manual switching through Android's keyboard picker depends on whether your phone shows auxiliary voice keyboards.

For a microphone shortcut, use HeliBoard. Download its official APK directly; no extra app store is required. Enable OpenVoiceIME, then pin Voice input in HeliBoard's toolbar settings.

Other speech APIs Deepgram, AssemblyAI, Google, and Azure need adapters

Privacy model

No OpenVoiceIME transcription backend.

Audio is sent to the endpoint you configure. API tokens are stored locally using encrypted app storage. Release builds block cleartext HTTP, so normal use should go through HTTPS.

Audio goes to your configured provider.

Transcript text is inserted into the active app.

Provider retention depends on the provider you choose.
